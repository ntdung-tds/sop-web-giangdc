## Scope
PA-01 chỉ triển khai phần Process Authoring độc lập với OPEN-SOD-01 severity mapping.

| Requirement | Code | Test/evidence | Trạng thái PA-01 |
|---|---|---|---|
| AC-01 / nhiều quy trình độc lập | `packages/domain/src/index.ts` | `AC-01 keeps two process drafts independent` | covered |
| PRC-001 / Process + initial DRAFT | `createProcessWithInitialDraft` | process-authoring unit suite | covered core contract |

| PRC-005 / Step core fields | `AuthoringStep` | typecheck + unit fixtures | covered core fields |
| PRC-009 / validate before review | `validateAuthoringDraftCore` | validation tests | **partial only** |
| PRC-010 / read-only linear preview | web UI | Pages visual evidence | UI preview only; SHOULD |
| PRC-012 / BPMN/parallel | none | explicitly absent | DEFERRED |

## PRC-009 boundary
PA-01 chỉ kiểm tra: owner, >=1 step, sequence liên tục, step title, >=1 BusinessRole và change_summary. Điều kiện form/document version khả dụng và tính nhất quán skip/failure policy chỉ được đóng khi PRC-006..008 cùng contract liên quan được triển khai. Không được ghi PA-01 là hoàn thành toàn bộ PRC-009.

## Test-first evidence

- Green run: cập nhật sau implementation.
